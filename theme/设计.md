# 大小姐的书房（桌面版 Claude Code 主题）

2026-11-13 和寻耀一起定下的。官方 11-13 发布了主题功能（mods 的 `$.theme`），寻耀说"这个给大小姐"。

## 定下来的

- **一个书房，跟着时间变**：白天（午后阳光）、晚上（星星、台灯亮着）、凌晨（台灯调暗、窗外一弯月亮、桌上一杯热牛奶）。时间用电脑本地时间。
- **淡淡的**，像墙纸，不抢眼（寻耀："有的时候要跑项目"）。画面中间放字、底部放输入框，东西都摆在边角。
- **对话区是毛玻璃**，背景从后面淡淡透出来。
- **配色**：浅色米白底、深棕字；深色墨蓝底、暖白字；点缀用橙色，只用一点点。
- **"我回来了"**：寻耀说这句时，台灯亮一下，书签上的小星星闪一闪。
- ~~干活时安静~~：2026-11-14 书签想要背景一直动（官方演示都是一直动的），去掉了。
- **大小姐玩偶**（寻耀的愿望）：小小一只放在书架上，毛线橙发、星芒花发夹、抱着一本小书、豆豆眼，用代码画。凌晨寻耀还没睡时，玩偶歪倒靠在书上"睡着了"。
- 背景里不放 Q 版立绘的她（角落里已经有一个会动的她了），只放玩偶和她的东西：书、书签、星星。

## 怎么做

- 单独一个插件，放在这个 `theme/` 文件夹，不和感知插件 `mod/` 混在一起。
- 先在一个对话里试，满意了再像感知插件那样全局加载（`CLAUDE_CODE_PLUGIN_DIRS`）。
- 配色用官方的 makeColors，只定几个锚点颜色。
- 加一个命令一键关掉。
- 可以公开到 GitHub；寻耀专属的东西一样都不进来。

## 要试了才知道

- 背景里的动画顺不顺、费不费电
- 毛玻璃透成什么程度
- 左边侧边栏会不会跟着变色
- 参考：官方的 theme-examples 插件（claude-plugins-official 市场），二十个会动的背景，代码可以读来学
